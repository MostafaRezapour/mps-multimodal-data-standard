# MPS Multimodal Data Standard: Community Working Draft

**Status: Open for community input**

This document is a starting structure for community development. It is not presented as a finalized standard.

## Scope

How should multiple data modalities from the same MPS experiment be linked so they can be interpreted and reused together?

## Principles

- Reuse and map to established standards where appropriate.
- Keep requirements practical for real MPS studies.
- Distinguish required, recommended, and optional information when useful.
- Support machine-readable data without losing biological context.
- Record unresolved questions transparently.

## Community input requested

- Link omics samples to imaging from the same MPS
- Define identifiers for longitudinal measurements
- Define metadata for MPS video data
- Define metadata for sensor time series
- Nominate public multimodal MPS datasets

## How to comment

Use the repository issue forms to propose fields, definitions, evidence, mappings, examples, or changes.
